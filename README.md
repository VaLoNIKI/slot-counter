# 小役カウンター（SlotCounter）

パチスロの小役やボーナスを、ロックしたまま数える iPhone アプリです（**iOS 18 以上**）。
Mac を使わず、GitHub Actions でビルドし、Windows の Sideloadly で無料 Apple ID 署名してインストールします。

## 機能

- **機種プリセット**：アプリ画面の上で機種を選びます
  | 機種 | 数える項目 |
  |---|---|
  | 汎用 | ベル、チェリー、スイカ、チャンス目 |
  | ジャグラー | ブドウ、チェリー、BIG、REG |
  | ハナハナ | ベル、スイカ、BIG、REG |
  - カウントと総G数は**機種ごとに別々に保存**されます。切り替えても消えません
  - 各項目の回数と確率（総G数 ÷ 回数）を表示します。BIG と REG がある機種は**ボーナス合算**（BIG+REG）の確率も表示します
  - 設定判別（設定 1〜6 の推測）はありません
- **入力方法は 2 つ**
  1. **コントロール**（iOS 18）：コントロールセンター、ロック画面の左右ボタン、アクションボタン（iPhone 15 Pro 以降）に置けます。**ロックしたまま、Face ID なし・アプリを開かずに**実行されます
     - 「ブドウ +1」「チェリー +1」「ベル +1」「スイカ +1」「チャンス目 +1」「BIG +1」「REG +1」「小役 直前を取消」の 8 個。必要なものだけ置いてください
     - どのコントロールも、**選択中の機種**の項目を +1 します。選択中の機種に無い項目（例：汎用でブドウ）を押した場合は数えず、「汎用にブドウはありません」と表示します
  2. **ライブアクティビティのボタン**：ロック画面と Dynamic Island（長押しで展開）のタイルを押すと +1、「取消」で直前を取り消します
     - ロック中に押すと、iOS の仕様で Face ID などの解除が求められ、解除後に実行されます
- ライブアクティビティには、選択中の機種の項目・回数・確率、総G数、ボーナス合算、「直前: ブドウ +1」のような直前の操作が出ます。機種を切り替えると表示も切り替わります
- アプリで「開始」を押すとライブアクティビティを表示し、「停止」で終了します
- カウントは端末に保存されます。ライブアクティビティは iOS の仕様で最長 8 時間で終わりますが、アプリで「再開始」を押せば続きから表示されます
- アプリ画面の項目行をタップしても +1 できます。「この機種をリセット」は選択中の機種だけをリセットします（確認つき）

### 仕組み（メモ）

- コントロールとライブアクティビティのボタンの Intent は `LiveActivityIntent` に準拠しているので、ウィジェット拡張ではなく**アプリのプロセスで実行**されます。保存とライブアクティビティの更新がその場で行われます（アプリが起動していなければ iOS が裏で起動します）
- アプリを前面に出さないよう、Intent には `supportedModes = .background`（iOS 26 以降）と `openAppWhenRun = false`（iOS 18）を指定しています。`supportedModes` は iOS 26 SDK が必要なので、ビルドは macOS 26 ランナーの Xcode 26 系で行います
  - 以前の Xcode 16（iOS 18 SDK）のビルドでは、`supportedModes` が Intent の情報に入らず、新しい iOS でコントロールを押すとアプリが開いていました
- 保存先は `Application Support/counter.json` で、保護レベルは `completeFileProtectionUntilFirstUserAuthentication` です。再起動後に一度ロック解除すれば、以降はロック中でも読み書きできます
  - 再起動直後で一度もロック解除していない間は、カウントできません（データを壊さないよう、読めない間は書き込みません）
- 旧版のカウント（機種プリセット前のもの、UserDefaults 保存のもの）は、初回起動時に自動で「汎用」に引き継ぎます

## 構成

```
project.yml                 XcodeGen 定義（.xcodeproj はコミットしない）
App/                        アプリ本体（画面、ライブアクティビティの開始/停止）
Widget/                     ウィジェット拡張（コントロール、ロック画面 / Dynamic Island の表示）
Shared/                     両ターゲット共通（小役定義、保存、AppIntent）
.github/workflows/build.yml       署名なし .ipa を作るワークフロー
.github/workflows/secret-scan.yml push ごとに gitleaks で秘密情報を検査するワークフロー
CLAUDE.md                         公開リポジトリとしてのセキュリティルール
```

- バンドルID：アプリ `com.valoniki.slotcounter`、ウィジェット拡張 `com.valoniki.slotcounter.widget`
  - 変える場合は `project.yml` の `PRODUCT_BUNDLE_IDENTIFIER` 2 か所（拡張はアプリIDの配下にすること）
- App Groups は使っていません（Intent はアプリのプロセスで動くので不要）

## ビルド（GitHub Actions）

`main` を含むどのブランチでも push するたびに macOS 26 ランナー（Xcode 26 系）でビルドされます。同時に `Secret scan`（gitleaks）が全履歴を検査します。手動実行は Actions タブの「Build unsigned IPA」→「Run workflow」。

1. GitHub のリポジトリ → **Actions** → 最新の成功した実行を開く
2. 下の **Artifacts** の `SlotCounter-ipa` をダウンロード
3. ダウンロードした zip を展開すると `SlotCounter.ipa` が出てくる（これを Sideloadly に渡す）

gh を使う場合（Windows の PowerShell で）:

```bash
gh run download --repo VaLoNIKI/slot-counter --name SlotCounter-ipa --dir .\ipa
```

`.\ipa\SlotCounter.ipa` に保存されます（gh は zip を自動で展開します）。

## Sideloadly でのインストール手順（Windows）

### 事前準備（PC）

1. **iTunes と iCloud を Apple 公式サイトから入手したデスクトップ版で入れる**（Microsoft Store 版だと Sideloadly が iPhone を認識しないことがあります）
2. [Sideloadly](https://sideloadly.io/) をインストール
3. iPhone を USB ケーブルで接続し、iPhone 側で「このコンピュータを信頼」→パスコード入力

### インストール

1. Sideloadly を起動
2. 左上の IPA アイコンに `SlotCounter.ipa` をドラッグ＆ドロップ
3. **iDevice** に自分の iPhone が出ていることを確認
4. **Apple account** に無料 Apple ID のメールアドレスを入力
5. **Start** を押し、求められたら Apple ID のパスワード（2 段階認証コード）を入力
   - パスワードは Sideloadly が Apple に送るためのもので、このリポジトリには関係ありません
6. 「Done.」と表示されれば完了

うまくいかないとき：
- 「バンドルIDが使えない」系のエラー：`project.yml` のバンドルIDを他と被らない名前に変えて push し、新しい ipa で再実行
- 「App ID の上限」系のエラー：無料 Apple ID は 7 日間に作れる App ID が 10 個までです（このアプリは本体＋ウィジェットで 2 個使います）。日を置くか、同じバンドルIDで入れ直してください

## iPhone 側で必要な設定

1. **デベロッパモードをオン**（iOS 16 以降で必須）
   - 一度 Sideloadly でインストールすると、**設定 > プライバシーとセキュリティ > デベロッパモード** が現れます
   - オン → 再起動 → 再起動後のダイアログで「オンにする」→パスコード入力
2. **開発元を信頼する**
   - **設定 > 一般 > VPN とデバイス管理** → 自分の Apple ID のデベロッパ App → 「信頼」
   - これをしないとアプリを開いたときに「信頼されていないデベロッパ」と出て起動できません
3. **ライブアクティビティを許可**
   - **設定 > 小役カウンター > ライブアクティビティ** をオン
   - **設定 > Face ID とパスコード > ロック中にアクセスを許可** の「ライブアクティビティ」がオンであること（オフだとロック中に表示・操作できません）

## コントロールの追加（iPhone 側）

インストール後に**一度アプリを開いてから**追加してください（コントロールの一覧に出てくるようになります）。
コントロールの名前は「ブドウ +1」「チェリー +1」「ベル +1」「スイカ +1」「チャンス目 +1」「BIG +1」「REG +1」「小役 直前を取消」です。一覧ではアプリ名「小役カウンター」の下に並びます。

置く数の目安：ジャグラーなら「ブドウ」「チェリー」「BIG」「REG」「取消」の 5 個、ハナハナなら「ベル」「スイカ」「BIG」「REG」「取消」の 5 個です。両方打つなら和集合（7 項目＋取消）を置いても構いません。

### コントロールセンター（全部置けるのでおすすめ）

1. 画面右上から下にスワイプしてコントロールセンターを開く
2. 空いている所を長押し（または左上の「＋」）→「コントロールを追加」
3. 検索欄に「小役」と入力するか、一覧から「小役カウンター」を探す
4. 「ブドウ +1」などをタップして追加。必要なものを全部追加できます
5. 置き場所はドラッグで調整。小役用に専用のページ（右側にスワイプした 2 ページ目など）を作ると押し間違いが減ります

ロック中でもコントロールセンターは開けます。開けない場合は、**設定 > Face ID とパスコード > ロック中にアクセスを許可 > コントロールセンター** をオンにしてください。

### ロック画面の左右ボタン（2 個まで）

1. ロック画面を長押し →「カスタマイズ」→「ロック画面」
2. 下の左右のボタン（初期状態は懐中電灯とカメラ）の「−」で外す →「＋」をタップ
3. 「小役カウンター」から「ブドウ +1」などを選ぶ（例：ジャグラーなら左 = ブドウ、右 = チェリー）
4. 右上の「完了」

ロック画面のボタンは、**長押し（触覚フィードバックがあるまで）**で実行されます。

### アクションボタン（iPhone 15 Pro 以降、1 個）

1. **設定 > アクションボタン**
2. 左右にスワイプして「コントロール」を選ぶ
3. 「コントロールを選択」→「小役カウンター」→ 使いたいもの（例：チャンス目 +1）

### 動作の確認

アプリで「開始」してからロックし、コントロールを押すと、**アプリは開かずに**ロック画面の表示の数字と「直前: ○○ +1」がすぐ変わります。変わらない場合やアプリが開いてしまう場合は「困ったとき」を見てください。

## 使い方

1. アプリを開き、機種（汎用／ジャグラー／ハナハナ）を選ぶ。必要なら総G数を入力
2. 「開始」→ ロック画面にカウンターが表示される
3. ロックしたまま、コントロールで +1／「直前を取消」。画面を見ながらなら、ライブアクティビティのタイルを押しても +1 できます
4. 総G数を更新したいときはアプリで入力し直す（ロック画面の確率・合算も更新されます）
5. 終わったら「停止」。別の機種を打つときはアプリで機種を切り替えて「開始」（前の機種のカウントは残ります）

## 困ったとき

- **コントロールの一覧に出てこない**：アプリを一度開く。それでも出ない場合は iPhone を再起動する
- **押しても数字が変わらない**：
  - 再起動直後で一度もロック解除していない間は、カウントできません。一度ロック解除してください
  - アプリをアプリスイッチャーから上にスワイプして終了していても通常は動きますが、動かないときはアプリを一度開いてから試してください
  - 「設定 > 小役カウンター > ライブアクティビティ」がオンか確認（カウント自体はされていて、表示だけ出ていない場合もあります。アプリを開けば回数を確認できます）
- **コントロールを押すとアプリが開いてしまう**：古い ipa（Xcode 16 でビルドしたもの）が入っている可能性があります。最新の ipa を入れ直し、コントロールを一度外して追加し直してください
- **押したのに「○○に△△はありません」と出る**：選択中の機種にその項目がありません。アプリで機種を切り替えてください
- **ライブアクティビティが消えた／表示が崩れた**：アプリで「再開始」を押してください（アップデート直後は古い表示が残ることがあります）
- **署名切れ（7 日）でアプリを入れ直したら、コントロールが消えた／反応しない**：一度アプリを開き、外れていたら追加し直してください

## 注意（無料 Apple ID の制限）

- **7 日で署名が切れます**。切れるとアプリが起動しなくなるので、7 日以内に Sideloadly で同じ ipa を入れ直してください（カウントはアプリを削除しなければ残ります）
- 無料 Apple ID で同時にインストールできるサイドロードアプリは 3 個までです
- Sideloadly を常駐させ、PC と iPhone を同じ Wi-Fi に置いておくと自動更新（Auto Refresh）も使えます
