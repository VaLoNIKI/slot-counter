# 小役カウンター（SlotCounter）

パチスロの小役やボーナスを数える iPhone アプリです（**iOS 18 以上**）。ロック中は「再生ボタン」方式で Face ID なしに数えられます。
Mac を使わず、GitHub Actions でビルドし、Windows の Sideloadly で無料 Apple ID 署名してインストールします。

## 機能

- **機種プリセット**：アプリ画面の上で機種を選びます
  | 機種 | 数える項目 |
  |---|---|
  | 汎用 | ベル、チェリー、スイカ、チャンス目 |
  | ジャグラー | ブドウ、チェリー、BIG、REG |
  | ハナハナ | ベル、スイカ、BIG、REG |
  - カウントと総G数は**機種ごとに別々に保存**されます。切り替えても消えません
  - 各項目の回数と確率（総G数 ÷ 回数）を表示します。BIG と REG がある機種は**ボーナス合算**（BIG+REG）の確率も表示します
  - 設定判別（設定 1〜6 の推測）はありません
- **入力方法は 4 つ**
  0. **ロック画面の再生ボタン（ロック中に Face ID なしで数えられるのはこれだけ）**：アプリで「再生ボタンで数える」をオンにすると、ロック画面の「再生中」の枠（音楽アプリと同じ場所）の ⏭ ⏮ ⏯ でカウントできます。詳しくは下の「ロック中に数える（再生ボタン）」
  1. **コントロール**（iOS 18）：コントロールセンター、ロック画面の左右ボタン、アクションボタン（iPhone 15 Pro 以降）に置けます。アプリは開かずに実行されます
     - **実機ではロック中に押すと Face ID（ロック解除）を求められました**。通れば +1 され、そのあとロック画面に戻ります（iOS の動き）
     - 「ブドウ +1」「チェリー +1」「ベル +1」「スイカ +1」「チャンス目 +1」「BIG +1」「REG +1」「小役 直前を取消」の 8 個。必要なものだけ置いてください
     - どのコントロールも、**選択中の機種**の項目を +1 します。選択中の機種に無い項目（例：汎用でブドウ）を押した場合は数えず、「汎用にブドウはありません」と表示します
  2. **ライブアクティビティのボタン**：ロック画面と Dynamic Island（長押しで展開）のタイルを押すと +1、「取消」で直前を取り消します
     - ロック中に押すと、iOS の仕様で Face ID などの解除が求められ、解除後に実行されます
  3. **ショートカット**：ショートカットアプリのアクション（「ブドウ +1」など 8 個）として使えます。**背面タップ**やアクションボタン、Siri（「小役カウンターでブドウ」など）から呼べます。こちらもアプリを開かずに実行されます（ロック中の動きはコントロールと同じく解除を求められる可能性があります）
- ライブアクティビティには、選択中の機種の項目・回数・確率、総G数、ボーナス合算、「直前: ブドウ +1」のような直前の操作が出ます。機種を切り替えると表示も切り替わります
- アプリで「開始」を押すとライブアクティビティを表示し、「停止」で終了します
- カウントは端末に保存されます。ライブアクティビティは iOS の仕様で最長 8 時間で終わりますが、アプリで「再開始」を押せば続きから表示されます
- アプリ画面の項目行をタップしても +1 できます。「この機種をリセット」は選択中の機種だけをリセットします（確認つき）

### 仕組み（メモ）

- コントロールとライブアクティビティのボタンの Intent は `LiveActivityIntent` に準拠しているので、ウィジェット拡張ではなく**アプリのプロセスで実行**されます。保存とライブアクティビティの更新がその場で行われます（アプリが起動していなければ iOS が裏で起動します）
- アプリを前面に出さないよう、Intent には `supportedModes = .background`（iOS 26 以降）と `openAppWhenRun = false`（iOS 18）を指定しています。`supportedModes` は iOS 26 SDK が必要なので、ビルドは macOS 26 ランナーの Xcode 26 系で行います
  - 以前の Xcode 16（iOS 18 SDK）のビルドでは、`supportedModes` が Intent の情報に入らず、新しい iOS でコントロールを押すとアプリが開いていました
- 保存先は `Application Support/counter.json` で、保護レベルは `completeFileProtectionUntilFirstUserAuthentication` です。再起動後に一度ロック解除すれば、以降はロック中でも読み書きできます
  - 再起動直後で一度もロック解除していない間は、カウントできません（データを壊さないよう、読めない間は書き込みません）
- 旧版のカウント（機種プリセット前のもの、UserDefaults 保存のもの）は、初回起動時に自動で「汎用」に引き継ぎます
- コントロールが実機でロック中に解除を求めた件：Apple のドキュメントに理由の明記はありません。ロック中にアプリ本体を起動して実行する種類の Intent だから、と考えています。拡張の中で動かす方法は、無料 Apple ID + Sideloadly では App Groups が使えない（アプリ本体とデータを共有できない）ため採れませんでした。そこで「再生ボタン」方式を追加しています

## ビルド（GitHub Actions）

`main` を含むどのブランチでも push するたびに macOS 26 ランナー（Xcode 26 系）でビルドされます。同時に `Secret scan`（gitleaks）が全履歴を検査します。手動実行は Actions タブの「Build unsigned IPA」→「Run workflow」。

1. GitHub のリポジトリ → **Actions** → 最新の成功した実行を開く
2. 下の **Artifacts** の `SlotCounter-ipa` をダウンロード
3. ダウンロードした zip を展開すると `SlotCounter.ipa` が出てくる（これを Sideloadly に渡す）

gh を使う場合（Windows の PowerShell で）:

```bash
gh run download --repo VaLoNIKI/slot-counter --name SlotCounter-ipa --dir .\ipa
```

`.\ipa\SlotCounter.ipa` に保存されます（gh は zip を自動で展開します）。

## Sideloadly でのインストール手順（Windows）

### 事前準備（PC）

1. **iTunes と iCloud を Apple 公式サイトから入手したデスクトップ版で入れる**（Microsoft Store 版だと Sideloadly が iPhone を認識しないことがあります）
2. [Sideloadly](https://sideloadly.io/) をインストール
3. iPhone を USB ケーブルで接続し、iPhone 側で「このコンピュータを信頼」→パスコード入力

### インストール

1. Sideloadly を起動
2. 左上の IPA アイコンに `SlotCounter.ipa` をドラッグ＆ドロップ
3. **iDevice** に自分の iPhone が出ていることを確認
4. **Apple account** に無料 Apple ID のメールアドレスを入力
5. **Start** を押し、求められたら Apple ID のパスワード（2 段階認証コード）を入力
   - パスワードは Sideloadly が Apple に送るためのもので、このリポジトリには関係ありません
6. 「Done.」と表示されれば完了

うまくいかないとき：
- 「バンドルIDが使えない」系のエラー：`project.yml` のバンドルIDを他と被らない名前に変えて push し、新しい ipa で再実行
- 「App ID の上限」系のエラー：無料 Apple ID は 7 日間に作れる App ID が 10 個までです（このアプリは本体＋ウィジェットで 2 個使います）。日を置くか、同じバンドルIDで入れ直してください

## iPhone 側で必要な設定

1. **デベロッパモードをオン**（iOS 16 以降で必須）
   - 一度 Sideloadly でインストールすると、**設定 > プライバシーとセキュリティ > デベロッパモード** が現れます
   - オン → 再起動 → 再起動後のダイアログで「オンにする」→パスコード入力
2. **開発元を信頼する**
   - **設定 > 一般 > VPN とデバイス管理** → 自分の Apple ID のデベロッパ App → 「信頼」
   - これをしないとアプリを開いたときに「信頼されていないデベロッパ」と出て起動できません
3. **ライブアクティビティを許可**
   - **設定 > 小役カウンター > ライブアクティビティ** をオン
   - **設定 > Face ID とパスコード > ロック中にアクセスを許可** の「ライブアクティビティ」がオンであること（オフだとロック中に表示・操作できません）

## コントロールの追加（iPhone 側）

インストール後に**一度アプリを開いてから**追加してください（コントロールの一覧に出てくるようになります）。
コントロールの名前は「ブドウ +1」「チェリー +1」「ベル +1」「スイカ +1」「チャンス目 +1」「BIG +1」「REG +1」「小役 直前を取消」です。一覧ではアプリ名「小役カウンター」の下に並びます。

置く数の目安：ジャグラーなら「ブドウ」「チェリー」「BIG」「REG」「取消」の 5 個、ハナハナなら「ベル」「スイカ」「BIG」「REG」「取消」の 5 個です。両方打つなら和集合（7 項目＋取消）を置いても構いません。

### コントロールセンター（全部置けるのでおすすめ）

1. 画面右上から下にスワイプしてコントロールセンターを開く
2. 空いている所を長押し（または左上の「＋」）→「コントロールを追加」
3. 検索欄に「小役」と入力するか、一覧から「小役カウンター」を探す
4. 「ブドウ +1」などをタップして追加。必要なものを全部追加できます
5. 置き場所はドラッグで調整。小役用に専用のページ（右側にスワイプした 2 ページ目など）を作ると押し間違いが減ります

ロック中でもコントロールセンターは開けます。開けない場合は、**設定 > Face ID とパスコード > ロック中にアクセスを許可 > コントロールセンター** をオンにしてください。

### ロック画面の左右ボタン（2 個まで）

1. ロック画面を長押し →「カスタマイズ」→「ロック画面」
2. 下の左右のボタン（初期状態は懐中電灯とカメラ）の「−」で外す →「＋」をタップ
3. 「小役カウンター」から「ブドウ +1」などを選ぶ（例：ジャグラーなら左 = ブドウ、右 = チェリー）
4. 右上の「完了」

ロック画面のボタンは、**長押し（触覚フィードバックがあるまで）**で実行されます。

### アクションボタン（iPhone 15 Pro 以降、1 個）

1. **設定 > アクションボタン**
2. 左右にスワイプして「コントロール」を選ぶ
3. 「コントロールを選択」→「小役カウンター」→ 使いたいもの（例：チャンス目 +1）

### 動作の確認

アプリで「開始」してからコントロールを押すと、**アプリは開かずに**ロック画面の表示の数字と「直前: ○○ +1」がすぐ変わります。ロック中に押すと Face ID を求められます（ロック中に Face ID なしで数えたいときは「再生ボタン」方式を使ってください）。

## 実戦画面（GUI）

デザイン案（Claude のデザインキャンバスで作った「D 決定案」）に合わせた、黒地の片手向けの1画面です。
- 上：機種名（タップで台・機種を切り替え）、直前の操作、再生ボタンが ON か、履歴とメニューのボタン
- 帯：**G数・ボーナス合算・ぶどう合算**（G数をタップすると総回転数の入力が重なって出る）
- 設定推測（暫定）：暫定の設定、平均、設定4以上の%、6本の小さな棒（ジャグラーのみ）
- 補足：ハマり、BIG、REG、単独REG の確率
- 下：親指で届く大きな4つのボタン（ジャグラー：ぶどう・チェリー・BIG・REG）と取消。押すと軽く振動します
- BIG / REG を押すと「単独・チェリー・判別不能」が重なって出ます（アニメーションなし）
- 再生ボタンの割り当て、ライブアクティビティ、実戦の保存、リセット、ボーナス履歴、スペック表、詳しい集計は「メニュー」にあります
- ハナハナは帯が「G数・ボーナス合算・ベル」、汎用は「G数・ベル・チェリー」になります

## ジャグラー向けの機能

### 機種（台）の選択とスペック表
「ジャグラー」を選ぶと、台を選べます（現行の6号機のみ）：マイジャグラーⅥ、ネオアイムジャグラーEX、ウルトラミラクルジャグラー、ミスタージャグラー、ジャグラーガールズSS、GOGOジャグラー3、ハッピージャグラーVⅢ、マイジャグラーⅤ、ファンキージャグラー2。
- 「スペック表」で設定1〜6の BIG／REG／合算／ぶどう／機械割と、今の実測値を並べて見られます
- BIG／REG／合算／ぶどうの確率の横に「設定4付近」のように、スペック表で一番近い設定を出します（設定推測ではありません。G数が少ないうちは大きくぶれます）
- 数値の出典：[ジャグラースペック一覧表（smokefield.info）](https://smokefield.info/slot/jugglerspec.html)

### 総回転数（データカウンター連動）
台のデータカウンターの総回転数を「打ち始め」と「現在」に入れると、**自分のG数 = 現在 − 打ち始め** を自動で計算します。確率はすべて自分のG数で計算します。最後のボーナスからの **ハマりG数** も出ます（ロック画面のライブアクティビティにも表示）。

### ボーナス履歴と重複の区別
- 「BIG」「REG」のボタンを押すと、その場に「単独／チェリー／判別不能」の選択肢が重なって出ます（アニメーションなし）。選ぶと記録されます
- 当選時の総回転数は記録しません。ボーナス間のG数やハマりを出したいときは、履歴をタップして総回転数を入れてください（最後のボーナスに総回転数がないとハマりは表示されません）
- BIG／REG／合算に加えて、**単独REG・チェリーREG・単独BIG・チェリーBIG** の回数と確率を表示
- ボーナス履歴（新しい順）に、種類・前のボーナスからのG数・当選時の総回転数を表示。タップで重複や総回転数を直したり、削除したりできます
- ロック画面の再生ボタン・コントロール・ライブアクティビティから BIG／REG を記録した場合は、重複「不明」・総回転数なしで記録されます。あとで履歴から直してください
- ハナハナは BIG／REG の2ボタン（重複の区別なし）

### 設定推測（暫定）
ジャグラーでは、BIG・REG・ぶどうの回数と自分のG数から、設定1〜6それぞれの可能性（%）を出します。「暫定 設定4」「平均 3.6」「設定4以上 58%」のように表示し、履歴の詳細にも出ます。
- 計算方法：選んだ台のスペック表の確率で、今の回数がそれぞれの設定でどれだけ起こりやすいかを比べる（ベイズ推定の簡易版。最初はどの設定も同じ確率とする）
- 使う項目：BIG・REG、**単独/重複の内訳**（単独BIG・チェリーBIG・単独REG・チェリーREG。判別不能のボーナスは BIG/REG 全体の確率で計算）、ぶどう、**チェリー**
- ぶどう・チェリーは1回以上数えているときだけ使います（数えていないのに0回として扱うと大きく狂うため）
- チェリーの設定差（ボーナスと重ならなかったチェリー＝非重複チェリー。チェリーと同時のボーナスは BIG/REG の「チェリー」で記録するので、チェリーのボタンの回数はこれに当たる）
  | 機種 | 設定1〜6 |
  |---|---|
  | マイジャグラーⅥ / Ⅴ | 1/38.1, 38.1, 36.8, 35.6, 35.6, 35.6（高設定ほど多い） |
  | ハッピージャグラーVⅢ | 1/62.1, 62.2, 62.7, 63.9, 64.5, 65.4（高設定ほど**少ない**） |
  | ネオアイム・ガールズSS・GOGO3・ファンキー2 | 全設定 1/35.6（設定差なし。推測には使わない） |
  | ミスター・ウルトラミラクル | 公式の設定別の値が見つからないため使わない |
- 単独/重複の内訳はミスター以外の8機種で使います（ミスターは資料に設定別の値がない）
- 数値の出典：ジャグラースペック一覧表と各機種の詳細ページ（smokefield.info）
- G数が少ないうちはあてになりません。あくまで目安です

### 実戦の保存と履歴
- 「実戦を保存して新しく始める」で、店名・台番（どちらも空欄可）を付けて保存し、その機種のカウントを0に戻します
- 右上の「履歴」から、保存した実戦の一覧（日付・店・台番・機種・G数・BIG/REG・合算・ぶどう）と詳細（ボーナス履歴を含む）を見られます。左にスワイプで削除
- 「この機種をリセット（保存しない）」は保存せずに0に戻します

### 将来の課金への備え（開発メモ）
- 有料にするかもしれない機能（履歴、スペック比較、設定推測）は `App/SessionArchive.swift` の `FeatureAccess.isUnlocked` を通して表示しています。今は全部無料。課金を入れるときはここを StoreKit の購入状態に差し替えます
- 保存データには版番号（`schemaVersion`）を付けています
- 注意：App 内課金は App Store（など正式な配布）でしか使えません。また「再生ボタン」方式は App Store の審査基準 2.5.4 に反するため、App Store に出す場合は外す必要があります

## ロック中に数える（再生ボタン）

音楽アプリのロック画面コントロールを流用する、少し強引な方法です。アプリが**無音の音声をループ再生**して「音楽を再生中のアプリ」になり、ロック画面の ⏮ ⏯ ⏭ ボタンでカウントします。音楽アプリと同じく、**ロック中でも Face ID なし**で押せます。

### 使い方

1. アプリで機種を選ぶ
2. 「ロック画面の再生ボタンでカウント」の **「再生ボタンで数える」をオン**
3. 割り当てを選ぶ（機種ごとに保存）
   | ボタン | 初期値（ジャグラー） | 初期値（ハナハナ） | 初期値（汎用） |
   |---|---|---|---|
   | ⏭ 次の曲 | ブドウ +1 | ベル +1 | ベル +1 |
   | ⏮ 前の曲 | チェリー +1 | スイカ +1 | チェリー +1 |
   | ⏯ 再生/一時停止 | 直前を取消（「何もしない」にもできる） | 同左 | 同左 |
4. iPhone をロック → 画面を点けると、ロック画面に「再生中」の枠が出る。⏭ ⏮ を押すとカウント、⏯ で直前を取消
   - 枠の曲名の欄に「⏭ブドウ 12 (1/6.2)  ⏮チェリー 3 (1/25.0)」、アーティスト名の欄に「直前: ブドウ +1 ・ ジャグラー ・ 3000G ・ 合算 1/150」のように出ます
   - ライブアクティビティを「開始」していれば、そちらの数字もすぐ変わります
5. 使い終わったらオフにする

### 背面タップ・音量ボタンで数える（実験的）

「再生ボタンで数える」がオンの間、メニューの「音量ボタン・背面タップでも数える（実験的）」をオンにすると、**音量＋で ⏭ の割り当て、音量−で ⏮ の割り当て**を +1 します（ジャグラーの初期値なら 音量＋ = ぶどう、音量− = チェリー）。

背面タップで使うには：
1. **設定 > アクセシビリティ > タッチ > 背面タップ**
2. 「ダブルタップ」→ **音量を上げる**、「トリプルタップ」→ **音量を下げる**（ショートカットではなく、一覧の上のほうにあるシステムの操作を選ぶ）
3. ロック画面で画面が点いている状態で背面をトントンと叩くと、曲名の欄の数字が増えます

注意：
- 実験的な機能です。iOS 18 以降はアプリが裏にいる間の音量の変化を受け取れないという報告があり、実機で動くかは未確認です
- 本体の音量ボタンを押しても数えます（音量は数えるたびに中間に戻ります）
- 背面タップの「ショートカット」に「ブドウ +1」を割り当てる方法は、ロック中は解除を求められる見込みです（コントロールと同じ）。ロック中に使うなら「音量を上げる／下げる」の方を使ってください

おまけ：AirPods などのイヤホンの操作も同じボタン扱いです（ダブルタップ = 次の曲、トリプルタップ = 前の曲、1 回 = 再生/一時停止）。

### 注意

- 使っている間は**他の音楽アプリと同時に使えません**。他のアプリで音楽を流すと、こちらが止まります（止まったらアプリを開いてオンにし直してください）
- 電話などで止まった場合は、終わったあと自動で再開します
- AirPods を耳から外したときやイヤホンを抜いたときに、iOS が「一時停止」を送ってくることがあります。⏯ が「直前を取消」だと誤って取り消されるので、イヤホンを使うときは ⏯ を「何もしない」にしてください
- 無音とはいえ音声を流し続けるので、電池は普段より少し減ります
- アプリを上にスワイプして終了すると止まります。次にアプリを開いたとき、オンのままなら自動で再開します
- 総G数と BIG/REG などボタンに割り当てていない項目は、アプリ画面で入力してください

## ショートカットから使う（背面タップ・アクションボタン・Siri）

アプリを一度開くと、ショートカットアプリに「小役カウンター」のアクションが自動で出てきます。

| アクション名 | Siri に言う例 |
|---|---|
| ブドウ +1 | 「小役カウンターでブドウ」 |
| チェリー +1 | 「小役カウンターでチェリー」 |
| ベル +1 | 「小役カウンターでベル」 |
| スイカ +1 | 「小役カウンターでスイカ」 |
| チャンス目 +1 | 「小役カウンターでチャンス目」 |
| BIG +1 | 「小役カウンターでビッグ」 |
| REG +1 | 「小役カウンターでレギュラー」 |
| 小役 直前を取消 | 「小役カウンターで取り消し」 |

どれも**選択中の機種**の項目を +1 します（コントロールと同じ動き）。アプリは開かず、ロック中でも実行されるように設定しています（`authenticationPolicy = .alwaysAllowed`、前面に出さない設定）。

### 背面タップ（iPhone の背面をトントンと叩く）

背面タップには「ダブルタップ」と「トリプルタップ」の 2 つを割り当てられます（例：ダブル = ブドウ +1、トリプル = 直前を取消）。

1. **ショートカットアプリ**を開く → 下の「ショートカット」タブ → 右上の「＋」
2. 「アクションを追加」→ 検索欄に「小役」と入力 → 「小役カウンター」の **「ブドウ +1」** をタップ
3. 上の名前を「ブドウ+1」などに変えて「完了」
4. 取消用にも同じ手順で「小役 直前を取消」のショートカットを作る
5. **設定 > アクセシビリティ > タッチ > 背面タップ** を開く
6. 「ダブルタップ」→ 下の「ショートカット」欄から 3 で作った「ブドウ+1」を選ぶ
7. 「トリプルタップ」→ 4 で作った取消のショートカットを選ぶ

メモ：
- 背面タップは**画面が点いている間**に反応します（ロック画面でも可。消灯中は反応しません）
- 実行すると画面上部に小さくショートカットのバナーが出ますが、アプリは開きません
- ケースが厚いと反応しにくいことがあります

### アクションボタン（iPhone 15 Pro 以降）

コントロールを割り当てる方法（上の「コントロールの追加」）の代わりに、ショートカットも割り当てられます。

1. **設定 > アクションボタン**
2. 左右にスワイプして「ショートカット」を選ぶ
3. 「ショートカットを選択」→ 「小役カウンター」の「ブドウ +1」など（または自分で作ったショートカット）を選ぶ

どちらでも動きは同じです。押したときに Dynamic Island にアイコンが出るのはコントロールの方です。

## 使い方

1. アプリを開き、機種（汎用／ジャグラー／ハナハナ）を選ぶ。必要なら総G数を入力
2. 「開始」→ ロック画面にカウンターが表示される
3. ロックしたまま数えるなら「再生ボタンで数える」をオンにして ⏭ ⏮ ⏯ で数える。コントロールやライブアクティビティのタイルでも +1 できます（ロック中は Face ID が必要）
4. 総G数を更新したいときはアプリで入力し直す（ロック画面の確率・合算も更新されます）
5. 終わったら「停止」。別の機種を打つときはアプリで機種を切り替えて「開始」（前の機種のカウントは残ります）

## 困ったとき

- **ロック画面に「再生中」の枠が出ない**：アプリで「再生ボタンで数える」がオンか確認。他の音楽アプリを再生していたら止めてから、オンにし直してください
- **⏭ ⏮ ではなく「15秒戻る／進む」のボタンが出る**：アプリを開いて「再生ボタンで数える」をオフ → オンにしてください
- **ショートカットアプリに「小役カウンター」のアクションが出てこない**：アプリを一度開いて数分待つ。それでも出ない場合は iPhone を再起動する
- **ショートカット実行時に「ロックを解除してください」と出る**：最新の ipa か確認してください。それでも出る場合は、ロック中はコントロール（コントロールセンター／ロック画面の左右ボタン）を使ってください
- **コントロールの一覧に出てこない**：アプリを一度開く。それでも出ない場合は iPhone を再起動する
- **押しても数字が変わらない**：
  - 再起動直後で一度もロック解除していない間は、カウントできません。一度ロック解除してください
  - アプリをアプリスイッチャーから上にスワイプして終了していても通常は動きますが、動かないときはアプリを一度開いてから試してください
  - 「設定 > 小役カウンター > ライブアクティビティ」がオンか確認（カウント自体はされていて、表示だけ出ていない場合もあります。アプリを開けば回数を確認できます）
- **コントロールを押すとアプリが開いてしまう**：古い ipa（Xcode 16 でビルドしたもの）が入っている可能性があります。最新の ipa を入れ直し、コントロールを一度外して追加し直してください
- **押したのに「○○に△△はありません」と出る**：選択中の機種にその項目がありません。アプリで機種を切り替えてください
- **ライブアクティビティが消えた／表示が崩れた**：アプリで「再開始」を押してください（アップデート直後は古い表示が残ることがあります）
- **署名切れ（7 日）でアプリを入れ直したら、コントロールが消えた／反応しない**：一度アプリを開き、外れていたら追加し直してください

## 注意（無料 Apple ID の制限）

- **7 日で署名が切れます**。切れるとアプリが起動しなくなるので、7 日以内に Sideloadly で同じ ipa を入れ直してください（カウントはアプリを削除しなければ残ります）
- 無料 Apple ID で同時にインストールできるサイドロードアプリは 3 個までです
- Sideloadly を常駐させ、PC と iPhone を同じ Wi-Fi に置いておくと自動更新（Auto Refresh）も使えます
